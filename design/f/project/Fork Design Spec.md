# Fork Design Spec

Версия 1.0 · июнь 2026 · тёмная тема — основная · реализация: Jetpack Compose + Material 3, без сторонних библиотек

Связанные макеты: **Fork Style Directions.dc.html** (логин / список чатов / чат во всех трёх темах).

---

## 1. Видение

Fork — мессенджер для своих: семьи и друзей. Привычный «телеграмный» UX, но визуально свежее, тише и дороже. Характер: уверенный, молодёжный, ночной.

**Принципы**

1. **UX не трогаем.** Каждый элемент стоит там, где его ожидает пользователь Telegram. Меняется только «кожа».
2. **Один градиент — много ролей.** Диагональный градиент индиго → циан (135°) — единственный цветной герой: отправка, непрочитанные, исходящие пузыри, онлайн-кольцо, waveform. Больше никаких произвольных акцентов.
3. **Глубина вместо шума.** Глубокие сине-серые поверхности, воздух 16–24dp, крупные радиусы. Ни линий, ни рамок там, где можно обойтись расстоянием.
4. **Крупная уверенная типографика.** Manrope, жирные заголовки с отрицательным трекингом; иерархия — весом и размером, не цветом.
5. **Физика, не спецэффекты.** Всё движение — короткие tween и пружины. Никаких Lottie, 3D и длинных шоу-анимаций.

## 2. Архитектура тем

Тема Fork = **Стиль × Режим**, переключается в Настройки → Оформление, хранится в DataStore.

| Ось | Значения | По умолчанию |
|---|---|---|
| Стиль | `aurora` / `frost` / `neon` | `aurora` |
| Режим | `light` / `dark` / `system` | `system` |
| AMOLED (чисто чёрный) | вкл/выкл — только при тёмном режиме | выкл |
| Material You (Android 12+) | вкл/выкл — динамические цвета поверх стиля | выкл |

**Три стиля:**

- **01 Aurora** — градиентный «кэп»-шапка, спокойные карточные поверхности. База.
- **02 Frost** — амбиентные свечения фона + стеклянные панели с blur (шапка, поиск, поле ввода, входящие пузыри).
- **03 Neon Ink** — почти чёрная база, крупнее типографика, градиент как неон: кольца, контуры, свечения.

**Правила композиции:**

- Светлый режим использует **общую светлую палитру** (§3.1); стили в нём отличаются только материалами: Aurora — градиентный кэп, Frost — стекло `rgba(255,255,255,0.65)` + blur над светлым фоном, Neon Ink — белая «бумага» с неоновыми кольцами/контурами без glow-теней.
- AMOLED подменяет в тёмной палитре активного стиля: `background/surface → #000000`, контейнеры → `#0B0F1A`, glow-тени −50% альфы.
- Material You: `primary/secondary/tertiary` и контейнеры берутся из `dynamicDarkColorScheme()` / `dynamicLightColorScheme()`; **Fork-токены не подменяются** — бренд-градиент строится из dynamic primary → dynamic tertiary, чтобы исходящие пузыри оставались градиентными.
- Скелет Compose:

```
ForkTheme(style, mode, amoled, dynamic) {
    MaterialTheme(colorScheme, ForkTypography, ForkShapes) {
        CompositionLocalProvider(LocalForkTokens provides forkTokens(style, ...)) { content }
    }
}
```

Смена стиля/режима — кроссфейд всего экрана: `tween 300ms, FastOutSlowIn` (анимация `animateColorAsState` по ключевым ролям либо crossfade контейнера).

## 4. Спецификации экранов

Все экраны edge-to-edge: контент под статусбаром и жестовой панелью. Размеры — для ширины 412dp.

### 4.1 Логин (телефон → код → пароль)

Первое впечатление; экран «продаёт» бренд.

**Структура (телефон):**
- Aurora: фон — полноэкранный `brandGradient`; градиент медленно «дышит» (сдвиг стопов, tween 6000ms touch-неблокирующий, реверс). Сверху по центру: вилка 74dp + «Fork» displayBrand + тэглайн bodyLarge белый 85%. Нижняя шторка surface, радиус 36, паддинг 24: заголовок headlineMedium, подсказка bodyMedium, поле страны 56dp (радиус 18), поле номера 56dp с префиксом «+7», кнопка «Продолжить» 56dp (капсула, brandGradient, elevation 3).
- Frost: фон background + три орба (`#2362FD` 45%, `#00B8D9` 32%, `#8B5CF6` 20%, blur 85–105dp), форма — стеклянная карточка `glassPanel` радиус 32 по центру, логотип-сквиркл 88dp.
- Neon Ink: фон почти чёрный с верхним свечением; «Fork» 72sp `brandGradientText`, лого-сквиркл 64dp с градиентным контуром 1.5dp; поле номера в градиентном контуре, кнопка с glow.

**Состояния:** фокус поля — бордер 1.5dp primary + ореол 4dp `rgba(35,98,253,0.14)` (Frost/Neon — циановый); ошибка номера/кода/пароля — бордер error + shake ±8dp spring (stiffness high) + подпись error 12sp; загрузка — текст кнопки → спиннер 24dp белый, кнопка не сжимается; код — 5 ячеек 52×60dp радиус 16, автопереход, заполненная подсвечивается бордером primary 150ms; пароль — поле с глазком, ссылка «Забыли пароль?» secondary.

**Переходы шагов:** shared-axis X (slide 30dp + fade, tween 300ms FastOutSlowIn); логотип уменьшается до 40dp и уезжает в шапку шага.

### 4.2 Список чатов

**Структура:**
- Шапка: Aurora — градиентный кэп (радиус низа 30, elevation 3): логотип+«Fork» titleLarge, аватар профиля 34dp; внутри поиск-капсула 46dp (белый 20%) и чипы-папки 32dp («Все» — белая активная, прочие белые 18%). Frost — стеклянная карточка (margin 12, радиус 28): «Чаты» titleLarge + поиск-капсула. Neon Ink — без подложки: «FORK» 12sp/трекинг 2.5 градиентом + «Чаты» headlineLarge; справа круглые кнопки 42dp поиск и профиль; табы-папки с градиентным подчёркиванием 3dp.
- Баннер обновления (если есть): карточка 20dp радиус: иконка-сквиркл 38dp brandGradient (стрелка вниз), «Доступно обновление» listTitle + версия bodyMedium, действие «Установить» labelMedium checkCyan. Свайп вправо — скрыть до следующей версии.
- Ячейка чата 76dp: аватар 56 (градиентная пара или фото; онлайн — `onlineRing`), имя listTitle + иконка mute 14dp; справа время timestamp; вторая строка — превью bodyMedium onSurfaceVariant (автор в группах — onSurface 60% w600; «Голосовое сообщение · 0:42» — checkCyan с иконкой микрофона 14dp), справа бейдж непрочитанных / галочки статуса 16×10dp.
- FAB (новое сообщение): 60dp brandGradient, иконка карандаш 24dp.

**Состояния:** пусто — вилка-контур 96dp onSurfaceVariant 40% + «Пока тишина» titleMedium + «Начните первый чат» bodyMedium + кнопка; загрузка — 8 ячеек-скелетонов (круг 56 + две полосы 14dp радиус 7, shimmer 1200ms); нет сети — статус в шапке «Подключение…» + три точки; выделение чата (long-press) — фон `rgba(35,98,253,0.07)`, чекбокс вместо аватара (flip 200ms).

### 4.3 Чат (главный экран)

**Шапка:** стрелка назад, аватар 46 с онлайн-кольцом, имя titleMedium, статус labelMedium («в сети» — checkCyan; Neon — градиентный текст; «была в 21:40» — onSurfaceVariant; «печатает…» — checkCyan + три прыгающие точки), меню ⋮. Aurora/Neon — на surface с hairline-границей; Frost — плавающая стеклянная карточка (margin 10, радиус 24), список скроллится под ней.

**Лента:** паддинг 12×14, группировка по авторам (§3.3), максимум ширины пузыря 78% (82% для голосовых).

| Тип сообщения | Спека |
|---|---|
| Текст | пузырь `bubbleIn/Out`, паддинг 10×14, message 16sp; время timestamp в правом нижнем углу, у исходящих + галочки 15×9dp |
| Фото/видео/GIF | пузырь-рамка паддинг 4, медиа радиусом `bubbleRadius−3`, max 252×320dp; время — капсула поверх `rgba(5,9,18,0.55)` + blur 6; видео — play 48dp по центру (`glassPill`), длительность в капсуле слева; GIF — бейдж «GIF» |
| Голосовое | play 42dp градиентный круг, waveform §3.3, «0:26 / 0:42» 12sp; прослушивание прокрашивает бары слева направо |
| Документ | иконка-сквиркл 42dp `primaryContainer` (глиф по расширению), имя listTitle 15sp, размер bodyMedium |
| Стикер | без пузыря, max 160×160dp, время капсулой рядом |
| Ответ (reply) | внутри пузыря: плашка радиус 10, In: белый 8% + бар 3dp brandCyan; Out: белый 18% + бар 3dp белый; имя labelSmall w800, сниппет 12.5sp, одна строка ellipsis |
| Дата-разделитель | по центру `glassPill`, радиус 14, паддинг 5×14, labelSmall |

**Поле ввода:** контейнер surface (Frost — стекло, Neon — градиентный контур 1.5dp), капсула 52dp: скрепка 21dp, placeholder «Сообщение» bodyLarge onSurfaceVariant 60%, смайл 21dp. Справа отдельная круглая кнопка 52dp: пусто — микрофон; есть текст — морф в отправку (§6).

**Запись голосового (удержание):** кнопка растёт ×1.6 spring; слева таймер «0:07» error-точкой 8dp (пульс 1с) и live-waveform; подсказка «← Отмена» — свайп влево гасит; свайп вверх — замок.

**Прочее:** кнопка «вниз» 46dp `glassPill` + бейдж непрочитанных (появляется при скролле >800dp, scale+fade 200ms); свайп пузыря вправо до 56dp — иконка ответа в круге 32dp, отпускание — spring назад; long-press — контекстное меню: scrim 45%, пузырь приподнят (scale 1.02), карточка меню 240dp радиус 20 elevation 4, пункты 48dp (Ответить, Копировать, Переслать, Закрепить, Удалить — error), реакции — ряд 6 эмодзи 40dp над меню.

**Состояния:** пусто — вилка-контур + «Напишите первым»; загрузка истории — спиннер-капсула 32dp сверху; не отправилось — часики → красный «!» в круге 16dp + повтор по тапу.

### 4.4 Поиск

Открывается тапом по поиску (Aurora/Frost — капсула раскрывается в шапку-поле, shared-element 250ms).

- Поле 46dp автофокус, «Отмена» labelLarge primary справа.
- До запроса: «Недавние» — горизонтальный ряд аватаров 56dp с именами 12sp; «Папки» чипами.

## 6. Моушн

Базовые кривые: `FastOutSlowIn` (вход/переходы), `LinearOutSlowIn` (появление), пружины `spring(dampingRatio, stiffness)`.

| Анимация | Спека |
|---|---|
| Переход список → чат | shared-axis X: slide 30dp + fade, tween 300ms FastOutSlowIn; назад — зеркально + predictive back (scale до 0.9) |
| Открытие медиа | container transform из пузыря, 300ms; закрытие — interactive dismiss |
| Новое сообщение | влетает снизу 24dp + fade 150ms + spring dampingRatio 0.8 stiffness medium (лёгкий подскок) |
| Отправка | пузырь вырастает из поля ввода: scale 0.85→1 spring 0.8 от нижнего правого угла |
| Микрофон ⇄ отправка | морф: иконка crossfade 120ms, фон серый→brandGradient 200ms, scale-пульс 1→1.12→1 spring 0.65 |
| Запись голосового | рост кнопки ×1.6 spring 0.7; пульс точки записи 1000ms повтор; отмена — slide-out влево 200ms |
| Waveform проигрывание | прокраска баров linear по позиции трека; активный бар +20% высоты spring 0.5 |
| Свайп-ответ | смещение пальцем с резистентностью (×0.6 после 40dp), возврат spring 0.75 stiffness medium; иконка появляется при 24dp scale 0.5→1 |
| Контекстное меню | scrim fade 150ms; меню scale 0.92→1 + fade, tween 200ms; реакции — каскад по 25ms |
| Бейдж непрочитанных | scale 0.6→1 spring 0.6; декремент — содержимое slide-up 150ms |
| Онлайн-кольцо | появление: fade + дуга разворачивается 360° tween 400ms; исчезновение fade 200ms |
| Капсулы (дата, «вниз») | fade + translateY 8dp, 200ms |
| «Дыхание» градиента (логин) | сдвиг центров стопов по диагонали, tween 6000ms, реверс, без задержки |
| Смена темы/стиля | кроссфейд 300ms FastOutSlowIn |
| Ripple | стандарт M3, цвет onSurface 8% (на градиенте — белый 16%) |
| Скелетоны | shimmer-градиент проход 1200ms linear, повтор |

Бюджет: одна анимация ≤ 400ms; всё прерываемое (Animatable/AnimatedVisibility); уважение «Удалить анимации» — заменять на fade 100ms.

## 7. Фирменные детали Fork

Дёшево в реализации, последовательно на всех экранах:

1. **Живой градиент бренда** — один диагональный градиент 135° на всех ключевых акцентах; на логине «дышит» (6с tween).
2. **Градиентные пузыри исходящих** — `bubbleOut` во всех стилях; входящие — спокойная поверхность/стекло.
3. **Онлайн-кольцо** — вместо зелёной точки: градиентное кольцо 2dp вокруг аватара, разворачивается дугой при появлении.
4. **Микрофон ⇄ отправка** — пружинный морф кнопки при первом введённом символе.
5. **Waveform в градиенте** — дорожка прокрашивается ступенями индиго→циан по мере проигрывания.
6. **Стеклянные капсулы** — дата-разделители, кнопка «вниз», оверлеи медиа: blur 8dp + tint 78%.
7. **Циановые галочки** — «прочитано» = `checkCyan`; на градиентных пузырях — белые.
8. **Пружинное появление** — сообщения влетают со spring-подскоком; свайп-ответ с физикой пружины.
9. **Вилка в пустых состояниях** — линейная иллюстрация-логотип одним контуром (stroke 1.6dp) для «нет сообщений», «ничего не найдено», «нет сети».
